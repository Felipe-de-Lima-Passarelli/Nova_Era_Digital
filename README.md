# 🚀 Nova Era Digital — Website Moderno e Responsivo

Este projeto é uma landing page moderna desenvolvida em **HTML + CSS**, com foco em design limpo, grid responsivo e apresentação profissional de serviços digitais.  
A proposta simula o site de uma agência chamada **"Nova Era Digital"**, destacando serviços, identidade visual e navegação intuitiva.

---

## 📌 Objetivo do Projeto

O projeto tem como metas:

- Treinar **HTML semântico**
- Criar **layout responsivo** usando Grid e Flexbox
- Trabalhar identidade visual e cores modernas
- Estruturar seções de serviços, destaque visual e rodapé profissional
- Praticar boas práticas de desenvolvimento front-end

---

## 🎨 Layout e Estrutura

O site contém:

### 🧭 **Cabeçalho**
- Logo / nome da marca  
- Menu horizontal  
- Botão de contato estilizado  

### 🖥️ **Seção Principal**
- Título de impacto  
- Texto de apresentação  
- Botão CTA  
- Imagem principal ao lado (com grid 2 colunas)  

### 🧩 **Seção de Serviços**
- Grid responsivo com 4 categorias:
  - Web Design  
  - Desenvolvimento  
  - Branding  
  - SEO & Marketing  

### 🦶 **Rodapé**
- Nome da marca  
- Links para redes sociais  
- Direitos autorais  

---

## 🧠 Tecnologias Utilizadas

- **HTML5**

## 📱 Responsividade

O layout adapta automaticamente para:

- **1200px** → serviços viram 2 colunas  
- **768px** → menu, grid principal e serviços viram 1 coluna  

Tudo fluindo de forma suave e coerente visualmente.

---

## 🚀 Como Executar

1. Baixe ou clone os arquivos
2. Coloque tudo na mesma pasta
3. Abra o arquivo **index.html** no navegador

Pronto!
